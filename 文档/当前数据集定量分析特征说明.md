# 当前数据集定量分析特征说明

核对日期：2026-09-18。本文依据当前工作区代码，说明 NeoResearch 的数据定量分析能力、字段含义、计算口径及解读限制；不代表某个具体数据集的实测结果。文中的数值示例仅用于解释。

## 1. 分析能力总览

当前定量分析由两部分组成：TSF domain 生成基础数据画像 `fingerprint.datasetProfile`，Data Analysis 模块在画像基础上读取数据，补充统计诊断并生成报告。数值计算是确定性的，不依赖 LLM；定性报告会进一步解释这些数值。

| 类别 | 已实现的分析 | 回答的问题 |
| --- | --- | --- |
| 数据规模与角色 | 行数、目标列数、参与统计的数值列数、目标/协变量角色 | 有多少数据？预测什么？哪些变量可能作为输入？ |
| 数据质量与时间轴 | 缺失率、重复时间戳、时间单调性、不规则间隔比例 | 数据是否完整？是否按规则时间顺序采样？ |
| 趋势与季节性 | 趋势强度、差分后的季节性强度 | 是否长期上升/下降？变化模式是否重复？ |
| 时间依赖 | 候选周期 ACF、连续滞后 ACF、近似 PACF | 当前值与多久以前的值有关？ |
| 平稳性 | ADF 风格统计量、KPSS 风格统计量 | 序列的统计行为是否相对稳定？ |
| 趋势/季节/残差分解 | 分解周期、三个成分的方差比 | 波动主要来自缓慢变化、周期重复还是剩余部分？ |
| 频域结构 | 主导频率对应周期、主频功率占比 | 哪种重复尺度最突出？频谱能量是否集中？ |
| 异常与变化 | 极端值比例、前后半段分布漂移、单个变化点 | 是否有极端观测？整体水平或波动是否发生变化？ |
| 多变量关系 | 同时刻相关性、相关矩阵、最强非零滞后相关 | 哪些目标共同变化？是否存在领先/滞后关系？ |
| 任务约束 | 上下文长度、预测长度、二者比例、资源限制 | 要预测多远？模型设计受到什么约束？ |

这里的“特征”主要指**数据集诊断指标**，并不意味着系统已将它们作为模型输入特征。

## 2. 先明确分析的数据范围

### 2.1 优先分析训练数据，但存在原始 CSV 回退

两层分析都优先寻找：

```text
<runtime.neoCastProjectRoot>/.neo-cast/dataset/<安全化的 loaderID>_train.csv
```

找到训练文件时，用训练文件计算统计指标。找不到时回退到 `dataset.path`，且两层回退范围不同：

| 情况 | 基础画像 | 补充统计诊断 |
| --- | --- | --- |
| 训练文件存在 | 全部训练行 | 全部训练行 |
| 训练文件不存在 | 原始 CSV 前 5000 个非空数据行 | 原始 CSV 全部非空数据行 |

因此，不能仅凭报告名称认定指标严格来自训练集。如果回退路径指向包含验证/测试区间的完整文件，分析也可能覆盖这些区间。

`rowCount` 还有单独的口径：存在训练文件且原始文件可读取时，它记录原始 CSV 的数据行数，而其他画像指标仍在训练文件上计算；原始文件不可读取时才退回训练行数。不存在训练文件时，它最多为 5000。**不能用 `rowCount` 直接推断所有指标的实际样本量。**

### 2.2 通常只对预测目标列做统计

有匹配列时，使用 `dataset.targetCols`。报告同时列出：

| 字段 | 含义 | 是否自动纳入当前目标统计 |
| --- | --- | --- |
| `targetCols` | 需要预测的目标 | 是 |
| `observedPastCovariates` | 预测时只能使用历史观测的协变量 | 不因声明该角色就纳入 |
| `knownFutureCovariates` | 预测时可提前知道的未来协变量 | 不因声明该角色就纳入 |
| `staticCovariates` | 不随时间变化的属性 | 不因声明该角色就纳入 |

例如，只预测功率、另有温度和风速两个协变量时，`targetCount=1` 不代表模型没有外生输入；目标间相关分析也不会自动评估“风速对功率的关系”。

目标列完全没有匹配时，两层的回退方式也不同：基础画像自动选择有效数值比例至少 50% 的列，最多 20 列；补充诊断直接选择表头第一列以外的列。正常匹配目标列时不受这个 20 列回退上限约束。

### 2.3 多列如何汇总

当前不是每项指标都逐列完整输出：

- 趋势、季节性、ADF、分布漂移等：逐列计算，再取均值。
- 异常值比例：将所有参与统计的目标值合并后计算。
- KPSS、分解、频域、变化点：先对同一时刻的目标值取算术平均，得到一条聚合序列，再分析。
- 相关矩阵：保留目标列对之间的结果；跨变量滞后只返回最强的一组结果。

聚合前没有标准化，因此大数值尺度的目标可能主导聚合序列，正负变化也可能相互抵消。报告描述的是汇总结构，不能保证每个目标都具有同样特性。

## 3. 数据规模与基础质量

### 3.1 规模字段

| 字段 | 含义 | 解读注意事项 |
| --- | --- | --- |
| `rowCount` | 画像记录的行数 | 具体口径见 2.1，不一定等于统计样本量 |
| `targetCount` | 画像实际使用的列数 | 正常为匹配的预测目标数；自动回退时可能是数值列数 |
| `numericColumnCount` | 实际参与画像的数值列数 | 当前与画像中的 `targetCount` 相同，不是全表所有数值列数 |
| `path` | 基础画像实际读取的文件路径 | 判断使用训练文件还是原始文件的重要依据 |
| `source` | 来源标签 | 当前固定为 `dataset.path`，即使实际读取训练文件；应结合 `path` 判断 |

### 3.2 缺失率 `missingRate`

```text
missingRate = 无法得到有限数值的目标单元格数 / (分析行数 × 分析列数)
```

基础画像把空字符串、非数值字符串和非有限值计为缺失。范围为 0～1，例如 `0.02` 表示参与统计的目标单元格有 2% 缺失，不是 2% 的行存在缺失。

它用于判断是否需要补值、缺失标记或检查采集问题，但不描述连续缺失段的长度，也不覆盖未参与统计的协变量。训练 CSV 若已完成补值，得到的零缺失率不能反推原始数据没有缺失。

**实现差异：**补充统计诊断直接使用 JavaScript `Number(cell)`，空字符串会转成 0；基础画像则先检查空字符串并转为缺失值。未清洗 CSV 可能因此在两层获得不同的结果。

## 4. 时间轴质量

基础画像优先识别名称为 `date`、`time`、`timestamp`、`datetime` 的列，忽略大小写；没有匹配时使用第一列。当前这部分没有直接按任务中的任意自定义时间列名定位。

| 字段 | 计算方式 | 含义与限制 |
| --- | --- | --- |
| `timestampColumn` | 实际选中的时间列名 | 可用于核对是否选对时间列 |
| `duplicateTimestampRate` | 重复数量 / 可解析时间戳数量；重复数量为总数减去去重后数量 | 越大表示同一时刻多条记录越多；无效时间戳不计入分母 |
| `monotonicTimestamp` | 检查相邻可解析时间戳是否严格递增 | `false` 表示存在倒序或重复；不是单独的重复率 |
| `irregularIntervalRatio` | 正时间间隔中，与中位正间隔相差超过 5% 的比例 | 越大表示采样间隔越不稳定；倒序和零间隔通过单调性指标反映，不计入这里的正间隔分母 |

例如，主要每小时采样，少量相邻记录相隔两小时，会提高不规则间隔比例。频域和滞后分析按行位置计算，不会自动把这种时间缺口换算成真实时间距离。

基础画像没有单独输出无效时间戳比例；可解析时间戳不足两个时，上述时间质量字段缺失。

## 5. 趋势与季节性

### 5.1 趋势强度 `trendStrength`

每个目标列计算时间与目标值的 Pearson 相关系数，取绝对值，再对列取平均：

```text
trendStrength = mean_j(|corr(time, x_j)|)
```

时间轴能够充分解析且严格递增时使用真实时间，否则使用有效观测的顺序索引。范围为 0～1。

- 接近 1：目标和时间有强线性关系，可能长期上升，也可能长期下降。
- 接近 0：没有明显的整体线性趋势，但仍可能存在曲线趋势、分段趋势或周期。
- 不保留方向和斜率，不能解读为“每小时增加多少”。

当前基础搜索偏好生成逻辑在 `trendStrength >= 0.2` 时添加 `trend`。这是工程规则，不是统计显著性判定。

### 5.2 季节性强度 `seasonalityStrength`

当前先做一阶差分，再检查有限个候选滞后：

```text
d_t = x_t - x_(t-1)
候选 lag = [24, 48, 96, 12, 7]，只保留 lag < (N-1)/2 的项
每列强度 = max_lag |corr(d_t, d_(t-lag))|
seasonalityStrength = 各列强度的均值
```

它描述“数值变化是否重复”，差分有助于减少纯线性趋势对季节性判断的干扰。范围为 0～1；当前基础偏好阈值为 `>= 0.4`。

例如，等间隔小时数据的 `lag=24` 对应一天；15 分钟数据的 `lag=96` 才对应一天。代码没有依据频率自动生成候选日/周周期。

这里使用绝对相关，反向交替模式也可能获得高分；低分也不代表没有周期，真实周期可能不在候选集合中。各列分别选最强滞后后再平均，因此高分不保证各列共享同一个周期。

## 6. 时间依赖：ACF 与近似 PACF

ACF 是自相关，用于描述序列与自身过去值之间的关系。当前有两套不同口径，不能混用。

### 6.1 基础画像的候选主周期

| 字段 | 计算与含义 |
| --- | --- |
| `acfMainPeriod` | 在 `[24,48,96,12,7]` 的有效候选中，选择目标列平均绝对自相关最大的 lag |
| `acfMainPeriodStrength` | 所选 lag 对应的平均绝对自相关，范围 0～1 |

这部分分析原始值，不做一阶差分，所以与 `seasonalityStrength` 不同。趋势也可能使原始序列在多个 lag 上高度相关；“最强候选 lag”不一定就是真实季节周期。

### 6.2 补充诊断的连续滞后 ACF

遍历 `1～min(40, floor(N/2))` 的 lag（代码最低保留 1）。每个 lag 先计算各目标的**带符号相关系数均值**，再按均值的绝对值选择最强项。

| 字段 | 含义 |
| --- | --- |
| `statistics.acf.topLag` | 连续扫描范围内，平均自相关绝对值最大的滞后步数 |
| `statistics.acf.topCorrelation` | 对应的带符号平均相关，范围 -1～1 |

正值表示同向关系，负值表示反向关系。例如 `lag=1, correlation=0.95` 更直接说明相邻时刻非常相似，不能单凭它断言“周期为 1”。不同列的正负相关会在平均时抵消。

### 6.3 近似 PACF

PACF 的概念是控制中间滞后影响后，观察当前值与某个历史值的直接联系。**当前代码只做如下简化计算，没有完整地控制所有中间滞后：**

```text
p_1 = r_1
p_k = r_k - r_(k-1) × r_1，k > 1
```

| 字段 | 含义 |
| --- | --- |
| `statistics.acf.pacfTopLag` | 近似值绝对值最大的 lag |
| `statistics.acf.pacfTopCorrelation` | 对应的近似值 |

可把它当作额外的滞后结构线索，不能当成标准 PACF 用来严格确定自回归阶数；结果也不保证满足标准相关系数的范围约束。ACF/PACF 当前都不输出显著性置信区间。无法计算的补充 ACF 项会被填为 0，因此零也可能表示不可计算。

## 7. 平稳性诊断

这里关注均值、波动和时间依赖是否相对稳定。当前两项均为简化诊断，不输出标准检验的 p 值，也不是逐目标完整检验报告。

### 7.1 ADF 风格诊断

每列拟合：

```text
Δx_t = α + β × x_(t-1) + ε_t
列统计量 = β / SE(β)
adfStatistic = 各列有效统计量的均值
adfStationary = (adfStatistic <= -3)
```

| 字段 | 含义 |
| --- | --- |
| `adfStatistic` | 描述前一期数值与后续增量之间回归关系的统计量；当前越负越倾向触发平稳判定 |
| `adfStationary` | 平均统计量是否达到代码固定阈值 -3 |

例如 `-4` 会判为 `true`，`-1` 会判为 `false`。但实现没有加入额外滞后差分项，也没有自动选阶；跨列统计量均值不能证明每一列都平稳。`false` 应理解为未满足这条诊断规则，而非已经证明非平稳。

### 7.2 KPSS 风格诊断

先将同一时刻的目标平均成聚合序列 `z_t`，去除非有限值，再计算：

```text
e_t = z_t - mean(z)
S_t = 从第一个观测到 t 的 e 累积和
kpssStatistic = sum(S_t²) / (N² × sampleVariance(z))
kpssStationary = (kpssStatistic < 0.463)
```

| 字段 | 含义 |
| --- | --- |
| `statistics.stationarity.kpssStatistic` | 偏离整体均值的误差是否长时间向一个方向积累；越大表示这种积累越明显 |
| `statistics.stationarity.kpssStationary` | 是否低于代码固定阈值 0.463 |

当前使用普通样本方差，未实现长期方差估计与带宽选择；检测的是围绕均值的行为，没有先去除拟合趋势。常量或过短序列可能不产生结果。

ADF 和 KPSS 同时倾向稳定，可以作为一致线索；相互矛盾时，需要结合趋势、漂移和各目标差异解释。这里两者的输入汇总方式本身就不同，不应直接视作严格的联合检验。

## 8. 趋势、季节与残差分解

当前报告称为 `STL-style decomposition`，实际过程是**中心移动平均 + 周期位置均值**，未调用完整的 LOESS STL。

1. 对聚合序列去除非有限值。
2. 周期 `P` 优先取 `acfMainPeriod`，缺失时取 12，再四舍五入并限制在 2 到 `floor(N/2)`。
3. 用中心移动平均得到趋势 `T_t`。半径为 `floor(P/2)`，内部窗口通常为 `2×floor(P/2)+1`，边缘缩短。
4. 对 `z_t-T_t` 按周期中的位置分组求均值，得到重复季节项 `S_t`。
5. 剩余项为 `R_t=z_t-T_t-S_t`。

| 字段（均位于 `statistics.decomposition`） | 计算方式 | 含义 |
| --- | --- | --- |
| `period` | 实际使用的 P | 分组重复的步数，不是独立检验确认的周期 |
| `trendVarianceShare` | `Var(T)/Var(z)` | 缓慢变化成分相对原序列的波动大小 |
| `seasonalVarianceShare` | `Var(S)/Var(z)` | 重复季节成分相对原序列的波动大小 |
| `residualVarianceShare` | `Var(R)/Var(z)` | 未被趋势和季节项表示的波动大小 |

这些方差比**不保证相加为 1，也不保证每项都小于等于 1**，因为各成分可能相关。它们不是互斥的解释率。残差大不等于纯随机噪声，可能还包含异常、错设周期、复杂动态或未纳入的外生因素。

中心移动平均使用观测点两侧的数据，适用于离线诊断；不能把此处生成的趋势直接当作预测时已经可用的因果输入特征。

## 9. 频域分析

对聚合序列去除非有限值并减去均值，直接计算离散傅里叶变换 DFT：

```text
扫描 k = 1 ... floor(N/2)，不包括零频率
power_k = real_k² + imag_k²
period_k = N/k
```

| 字段（位于 `statistics.frequency`） | 含义 |
| --- | --- |
| `dominantPeriod` | 功率最大的频率对应的周期，单位为观测步，可为小数 |
| `dominantPowerShare` | 该频点功率 / 当前扫描频点功率之和，范围 0～1（总功率为正时） |

主频占比较高，说明能量集中于某个重复尺度；较低则可能有多个周期、宽频波动或噪声。小时等间隔数据的周期 24 可解释为约一天，但需先确认时间轴规则。

当前只去均值，未去趋势、加窗或输出多个频谱峰。长期趋势可能形成低频峰；常量序列可能有一个被选中的周期但没有有效功率占比，因此周期必须结合功率解读。算法直接累加 DFT，计算量约为 O(N²)，没有 FFT 或自动降采样。

## 10. 极端值、分布漂移与变化点

### 10.1 极端值比例 `outlierRate`

将所有参与画像的目标列有限数值合并、排序，使用数组位置 `floor(0.25M)` 和 `floor(0.75M)` 取 Q1、Q3：

```text
IQR = Q3-Q1
下界 = Q1-3×IQR
上界 = Q3+3×IQR
outlierRate = 严格落在上下界以外的数量 / 有限数值总数
```

例如 `0.01` 表示 1% 的有限目标数值落在这些边界外。当前使用 **3 倍 IQR**，并且不是逐列独立计算；不同目标量纲混合可能掩盖异常或造成误判。有限值不足 8 个或 IQR 不大于 0 时返回 0，因此零值不能保证没有异常。

它检测的是全局极端值，不是“相对当天同一时刻异常”、局部突变或业务规则违规；被标记的峰值也可能是真实事件。

### 10.2 分布漂移 `distributionShift`

按分析数据的行顺序从中点切成前半段和后半段。每列计算：

```text
meanShift = |后半均值-前半均值| / 全段标准差
stdShift  = |后半标准差-前半标准差| / 全段标准差
列漂移分数 = meanShift + 0.5×stdShift
distributionShift = 各列漂移分数的均值
```

这里标准差使用总体口径。近似常量列的分数置 0，判定界限为全段标准差不大于 `max(1e-9, |全段均值|×1e-6)`。

分数越大，表示前后两段的水平或波动幅度差异越明显；它不是概率，不限制在 0～1。当前基础搜索偏好在 `>=0.5` 时添加 `distribution_shift`。

该分析不是训练集与测试集的显式比较，也不是完整分布距离：均值和标准差相同、但形状不同的两段可能仍得到低分。连续趋势也会提高它。

### 10.3 变化点 `statistics.changepoint`

在聚合序列上寻找一个前后均值差最大的切分位置：

```text
minWindow = max(6, floor(0.1N))
候选切分 i：minWindow ... N-minWindow
score_i = |mean(z[0:i])-mean(z[i:N])| / 全段样本标准差
选择 score 最大的位置
```

| 字段 | 含义 |
| --- | --- |
| `index` | 切分位置；左侧为 `[0,index)`，右侧为 `[index,N)` |
| `score` | 最强切分的标准化均值差；不是显著性概率 |
| `severity` | `score>=1` 为 `high`；`0.5<=score<1` 为 `medium`；其余为 `low` |

`index=120` 表示左侧有 120 个有效聚合观测，不是 CSV 文件第 120 行，也不是时间戳；缺失值过滤后尤其需要重新映射到原始时间。

只要样本量和方差满足要求，代码就选出一个最大值位置；出现 `index` 不等于确认发生了结构变化。当前不进行多变化点检测，也不直接检测纯方差突变。缓慢趋势也可能产生较高得分。

## 11. 多变量关系

### 11.1 同时刻相关性

| 字段 | 计算方式 | 解读 |
| --- | --- | --- |
| `crossVarCorrelation` | 所有目标列对的 Pearson 相关取绝对值后求均值 | 0～1；越大表示目标之间线性联动越强，不保留方向 |
| `correlationMatrix.columns` | 矩阵对应的目标列名 | 确认实际分析了哪些变量 |
| `correlationMatrix.values` | 带符号的两两 Pearson 相关矩阵 | -1～1；正值同向、负值反向、接近零表示线性相关弱 |

当前 `crossVarCorrelation>=0.5` 会触发基础搜索偏好 `cross_var_correlated`。单目标时返回 0，因为没有可计算的列对，并不说明协变量无用。

相关矩阵使用双方均为有限值的配对观测。有效配对不足三个或方差为零时，基础 Pearson 函数返回 0；矩阵对角线固定为 1，包含常量列，因此该矩阵不是常量列质量检查结果。矩阵在基础画像和综合分析报告中提供，定量报告指标表主要展示相关性汇总值。

### 11.2 跨变量滞后相关

扫描所有不同目标列组成的有向列对，并扫描非零正负 lag；最大绝对 lag 为 `min(24,maxLag)`，其中 `maxLag=max(1,min(40,floor(N/2)))`。相关计算配对的是：

```text
corr(source[t], target[t+lag])
```

仅保留全部候选中绝对相关最强的一组：

| 字段（位于 `statistics.crossLag`） | 含义 |
| --- | --- |
| `source` | 配对关系左侧目标列 |
| `target` | 配对关系右侧目标列 |
| `lag` | 正值表示 source 的较早观测对应 target 的较晚观测；负值表示方向相反 |
| `correlation` | 最强关系的带符号相关系数，范围 -1～1 |

例如 `source=A, target=B, lag=3, correlation=0.8` 表示 A 在时刻 t 的值与 B 在 t+3 的值有较强正线性联系，可形成“A 可能领先 B 三步”的建模假设。

它不证明因果关系，也未控制共同趋势、季节性或其他变量。交换 source/target 并反转 lag 会产生等价关系，不能只看箭头方向。当前只输出一个最强关系，没有全量排名、显著性校正或时间稳定性评估。

## 12. 任务约束与搜索偏好

这些是任务配置，不是通过数据估计出的统计特征：

基础画像转搜索偏好的规则汇总如下：

| 条件 | 生成偏好 | 可支持的建模方向 |

## 14. 数据准备阶段还有一套质量画像

`neo_cast/py/prepare_tsf.py` 的 `dataset_profile.v1` 主要用于数据准备与质量检查，应与上面的 `fingerprint.datasetProfile` 区分。

| 字段 | 含义 |
| --- | --- |
| `rows`、`feature_columns` | 该画像覆盖的数据行数和配置特征列 |
| `missing.total_missing` | 特征列缺失单元格总数 |
| `missing.feature_missing` | 各特征列分别缺失多少个值 |
| `time.timestamp_col`、`time.total_rows` | 采用的时间列和检查行数 |
| `time.invalid_timestamp_count` | 无法解析的时间戳数量 |
| `time.duplicate_timestamp_count` | 重复时间戳数量；存在无效时间戳时该值置 0，需先看无效数 |
| `time.monotonic_increasing` | 时间是否单调非递减；重复另行检查，存在无效时间戳时为 false |
| `time.inferred_frequency` | pandas 推断出的频率；无法推断时为 null |
| `time.median_delta_seconds` | 相邻时间间隔中位数，单位秒 |

特别注意：Python 的不规则间隔判定为**不等于中位间隔**，TSF 基础画像为**正间隔相对中位正间隔偏差超过 5%**。两者不能当成同一指标直接比较。准备阶段画像的作用主要是核对输入质量和处理效果，不等同于训练文件上的高级统计诊断。

## 15. 如何综合阅读一份报告

建议按以下顺序阅读：

1. **核对范围。** 查看 `path`、目标列和训练文件状态，确认哪些数据真正参与统计。
2. **检查质量。** 查看缺失、重复、时间单调性和采样间隔，并与准备阶段画像对照。
3. **看可利用的结构。** 联合阅读趋势、差分季节性、候选主周期、连续 ACF 和主频，判断证据是否一致。
4. **看稳定性。** 联合阅读 ADF/KPSS 风格诊断、前后段漂移和变化点，避免只根据一个布尔值下结论。
5. **看变量关系。** 先确认目标与协变量角色，再阅读相关矩阵和滞后方向。
6. **形成待验证的假设。** 将统计结构转为候选建模方向，通过训练和验证确认收益。

例如，若差分季节性较强、候选主周期为 24、DFT 主周期也接近 24，三者共同支持“约 24 步存在重复结构”的假设；若只有原始序列 ACF 高，而差分季节性低、趋势强，则应先考虑趋势或持续性造成的相关。

`n/a`、`-` 或缺失字段应解释为不可用或未计算，不能当成“无风险”。部分函数还会在短序列、常量列或无有效配对时返回 0，所以零值也要结合可计算条件解读。
