## 2. 总体探索路线

本轮探索遵循了一个比较清晰的收敛逻辑：

1. 先用 DLinear / decomposition MLP 建立低复杂度基线，确认任务下限大约在 `val_mse=0.072-0.076`。
2. 引入 `instance_norm` 类 RevIN 归一化后，Transformer / TimesNet / NLinear 的验证误差明显下降，说明该数据切分下“按样本窗口消除局部均值/尺度”是关键稳定器。
3. Transformer 系列长期停在 `0.065-0.066` 区间，容量放大没有带来显著收益，说明普通 attention 的边际收益有限。
4. TimesNet 在 `hidden_dim=96, top_k=3/7` 附近突破到 `0.0638`，后续通过 top-k、loss、学习率、warmup 和复现实验确认最佳组合。
5. PatchTST、Mixer、SSM、RNN 等分支多数没有突破 TimesNet，更多用于排除替代架构。
6. 最终 champion 是 `TimesNet + instance_norm + Huber + top_k=7 + cosine warmup=15 + lr=5e-5`，验证 MSE 稳定复现到 `0.062759`。

从研究思路看，本轮不是盲目扩大模型，而是逐步确认：ETTh1/OT 单变量 H96 任务中，局部归一化和多周期频域建模比单纯增加 attention 层数更有效。

## 3. 阶段性轨迹

### 阶段 A：线性与分解基线

初始候选包括 DLinear、decomposition MLP 和 dual DLinear。它们验证 MSE 在 `0.072-0.076` 之间，说明经典分解/线性结构能工作，但无法充分捕获剩余周期模式。此阶段的价值是建立“非深度复杂结构”的性能底线。

代表结果：

- `tsf_baseline_dlinear`: `val_mse=0.072132`
- `recipe_decomp_mlp_v1`: `val_mse=0.075260`
- `recipe_decomp_dual_dlinear_late_fusion_v1`: `val_mse=0.075532`

### 阶段 B：RevIN/instance_norm 成为稳定基座

当候选切换到 `instance_norm` 后，Transformer、TimesNet、NLinear 的结果整体进入 `0.063-0.068` 区间。NLinear 自身达到 `0.0677` 左右，虽然不是最终最优，但它证明“先去除窗口级偏移，再预测残差/模式”是可靠方向。

代表结果：

- `recipe_nlinear_revin_huber_cosine_v2`: `val_mse=0.067765`
- `recipe_nlinear_revin_mse_v3`: `val_mse=0.067904`
- `recipe_nlinear_revin_mse_long_v4`: `val_mse=0.067781`

### 阶段 C：Transformer 分支进入平台区

轻量 Transformer 起步较好，但后续增加参数、加深 encoder-decoder、加入 FFT/gating 或 PatchTST 变体，基本仍停在 `0.065-0.066` 区间。它们优于线性分解基线，但没有突破 TimesNet 分支。

代表结果：

- `recipe_lightweight_transformer_v1`: `val_mse=0.066070`
- `recipe_transformer_best_epoch_checkpoint_v4`: `val_mse=0.066144`
- `recipe_transformer_2layer_revin_v2`: `val_mse=0.065672`
- `recipe_gated_fft_transformer_v1`: `val_mse=0.065672`
- `recipe_patchtst_v3_dense_patch`: `val_mse=0.066179`

结论：普通 attention/patch attention 对该单变量 H96 任务有帮助，但不是主导增益来源。

### 阶段 D：TimesNet 突破

TimesNet 分支把建模重点转向频域多周期模式。早期 `acf7` 配置达到 `0.066002`，随后 `hidden_dim=96` 的 wider TimesNet 到达 `0.063867`，已经显著优于 Transformer 平台区。

关键假设是：ETTh1 的 OT 序列存在强周期性，ACF 主周期 7 的强度很高，TimesNet 的 2D FFT/Inception-style 卷积能够在去趋势/归一化后的残差中学习多周期结构。

代表结果：

- `recipe_timesnet_acf7_v1`: `val_mse=0.066002`
- `recipe_timesnet_wider_plateau_v2`: `val_mse=0.063867`
- `recipe_timesnet_revin_only_corrected_v6`: `val_mse=0.063867`
- `recipe_timesnet_revin_only_mse_v7`: `val_mse=0.063448`

### 阶段 E：top_k=7 与训练策略调参

在确认 TimesNet 有效后，探索集中到 top-k 频率数、学习率、warmup、loss 和稳定性。`recipe_timesnet_topk7_nlinear_v1` 首次达到 `val_mse=0.062759`，成为本轮 champion。

该候选的核心设计：

- backbone: TimesNet
- top_k: `7`
- hidden_dim: `96`
- n_layers: `2`
- kernel_size: `7`
- preprocessing: `instance_norm`
- loss: `Huber`
- optimizer: Adam, `lr=5e-5`
- scheduler: cosine, `warmup_steps=15`
- dropout: `0.1`
- grad_clip: `1.0`
- max_epochs: `50`
- patience: `7`

这个设计不是单纯扩大模型，而是保留稳定的 NLinear/RevIN 思路，只把 encoder 的周期建模能力增强到 `top_k=7`，以覆盖更多次主导频率。

### 阶段 F：替代架构排除

后续尝试了 Mixer、SSM、RNN、PatchTST、encoder-decoder Transformer 等路径，但没有超过 TimesNet champion。

代表结果：

- `tsf_ranked_invert_rnn_feature_profiled`: `val_mse=0.067085`
- `tsf_ranked_frequency_mixer_profiled`: `val_mse=0.076235`
- `recipe_mixer_revin_stabilized_v3`: `val_mse=0.066746`
- `tsf_ranked_ssm_graph_profiled`: `val_mse=0.066556`
- `recipe_ssm_nlinear_champion_recipe_v1`: `val_mse=0.067149`

结论：这些分支证明“更换架构家族”没有比“保留 TimesNet 多周期归纳偏置并细调训练策略”更有收益。

### 阶段 G：消融与复现

最后阶段围绕 champion 做消融和复现：

- `top_k=1` 消融：稳定重跑 `val_mse=0.065346`，比 champion 差约 `4.1%`，说明 multi-period FFT 是关键组件。
- MSE loss 消融：稳定重跑 `val_mse=0.062866`，比 champion 差约 `0.17%`，说明 Huber 有小但稳定的收益。
- champion 直接复现：`recipe_champion_direct_repro_v2` 复现 `val_mse=0.062759`，确认不是单次幸运初始化。

## 5. 最终模型设计思路

最终设计可以概括为：

> 用 `instance_norm` 把每个输入窗口的局部尺度和偏移先消掉，再用 TimesNet 的 multi-period FFT 表示学习 OT 序列中的多个周期成分，最后用线性 head 输出 H96 点预测。

关键设计选择如下：

| 组件 | 最终选择 | 原因 |
|---|---|---|
| normalization | `instance_norm` | 多数优胜候选都依赖它；没有它的分解/线性模型误差明显更高 |
| backbone | TimesNet | 比 Transformer、PatchTST、Mixer、SSM 更能利用周期结构 |
| top_k | `7` | top_k=1 消融明显退化，说明多周期频率覆盖是核心收益 |
| hidden_dim | `96` | wider TimesNet 首次突破 `0.064` |
| loss | Huber | 相比 MSE 有小幅稳定收益，且抗异常点更稳 |
| lr/scheduler | `5e-5 + cosine + warmup=15` | 在 champion 配置上稳定复现 |
| grad_clip | `1.0` | 保持 TimesNet 训练稳定 |

## 6. 结果解读

本轮最重要的结论不是“TimesNet 参数更多所以更好”，而是：

1. ETTh1/OT 的 H96 预测受局部尺度漂移影响明显，`instance_norm` 是基础稳定器。
2. 单纯的线性去趋势和 DLinear 分解不够，需要更强的周期残差建模。
3. 普通 Transformer/patch attention 有提升，但多次调参后停在平台区。
4. TimesNet 的 multi-period FFT 归纳偏置与该任务更匹配。
5. `top_k=7`、Huber、低学习率、warmup 和梯度裁剪是共同适配组合，单独改动容易回到 `0.063-0.066` 区间。

最终指标：

| 指标 | 值 |
|---|---:|
| best val_avg_mse | `0.062759` |
| best val_avg_mae | `0.189977` |
| ref_test_avg_mse | `0.098356` |
| ref_test_avg_mae | `0.241023` |
| params | `0.955201M` |
| training time | about `153-155s` |

需要注意：验证集和 ref-test 之间存在明显 gap（`0.062759 -> 0.098356`）。这不一定表示泄漏或错误，可能来自 ETTh1 后段分布变化；但如果要发布为 benchmark 结果，应补充多 seed 与更严格的 test-only 冻结流程。

## 7. 后续建议

1. 多 seed 复验 champion：至少 seed `0/42/1234`，报告均值和标准差，而不是只报告单次最优。
2. 保留 ref-test 调用频率约束：只在候选冻结后评估，避免把 test feedback 变成搜索信号。
3. 增加 horizon 扩展实验：在 H192/H336/H720 下验证 TimesNet top_k=7 是否仍然成立。
4. 做数据分段误差分析：定位 ref-test gap 来自季节切换、趋势漂移还是极值区间。
5. 将 `recipe_timesnet_topk7_nlinear_v1` 固化为 ETTh1/OT/H96 的推荐 recipe，并把消融结果写入 recipe prior / memory。
