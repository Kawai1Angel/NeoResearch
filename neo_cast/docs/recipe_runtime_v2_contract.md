# Recipe Runtime v2 Contract


> 2026-09-27 update: Removed `direct_multi_horizon` from schemas, registry, factory, and search entrypoints; legacy configurations are explicitly rejected rather than converted to another head. `gated_depthwise_conv` / `timesnet_lite` preserve requested even kernel sizes with asymmetric padding. Defaults apply only to missing fields; explicit invalid values and incompatible embedding return validation errors for agent correction. Old even-kernel checkpoints require retraining and are not converted automatically.
This document freezes the third design checkpoint of the semantic correction plan.

- Proposal use `recipe_schema_v2`; the ModelRecipe DSL remains `model_recipe.v1` and compiles to v2. Checkpoints must include `runtime_semantics_revision=2`; missing or mismatched revisions require retraining.
- Checkpoints and metadata.training_summary store a manifest for every H and a combined `model_manifest_digest`. Parameter-graph digests include actual modules, parameter shapes, and effective dropout/gate/residual switches. Standalone export loading verifies the parameter graph.
- All encoders return `[B,C,D]`. Internally `[B*C,D]` is allowed, but public `encode` uses the common shape. D is min(input_len,64), independent of horizon. Only the head performs the final `[B,C,D] -> [B,H,C]` projection, except the independent decomposition trend branch.
- Linear heads share a linear projection; direct heads have a nonlinear tower per lead step. Quantile/Gaussian/residual heads consume latent representations directly. Models train separately for each H; cross-task horizon sharing is not implemented.
- Linear backbone shared=false uses independent encoders per channel. Variable-token paths follow the same latent contract. `variate_attention` applies self-attention to variable tokens; `feature_mlp` applies an MLP along the original channel axis.
- Ordered fusion implements explicit gate/residual formulas over latent representations or inputs, with input-conditioned channel gates. Gated hybrid combines temporal and independent feature encoder latents; time gates refer to historical time, aggregated into latent mixing weights, rather than forecast horizon.
- Graph correlation is fitted on the current training fold; static topology requires an artifact with ordered channel_names. Adjacency persists in model_config/state_dict and contributes to the manifest digest.
- Decomposition is a preprocessing wrapper: an independent Linear(T,H) predicts the trend, while the recipe encoder/head predicts residuals. The branches share no parameters.
- Dropout is configured per module; training regularization.dropout is removed. Missing masks are saved before materialization imputes values. Models receive imputed values and a separate mask; model-level fill_policy is no longer supported.
- `missing_mask` must precede transformations, requires mask_channel=true and cross-variable fusion so targets can observe appended masks. Rematerialize old data without mask columns. CV restores missing positions from the original mask and refits imputation/scalers on each fold's training rows.
- One explicit semantic alias remains: `temporal/channel_mode=shared` and `feature_mlp` are both ChannelMixer on the original sequence. The manifest marks this through `fusion_equivalence`; research attribution must not count them as separate mechanisms. `sample_reweighting/uniform` explicitly means no sample reweighting.
- Exported `history`/`target_history` contain imputed values. `missing_mask` records original missingness in target+past order as `[T,C]` (1=missing) without overwriting imputed values again. Direct model calls with raw NaN use standardized-space zero fallback only; this does not replace the data-cleaning contract.
- `ssm` is renamed `gated_depthwise_conv`, with state_dim renamed hidden_dim; `timesnet` becomes `timesnet_lite`, marked paper_derived rather than a complete paper reproduction.
